# shoon-file

브라우저에서 바로 실행할 수 있는 간단한 **우주 총게임**입니다.

## 실행 방법

아래 명령으로 로컬 서버를 실행한 뒤 브라우저에서 접속하세요.

```bash
python3 -m http.server 4173
```

그 다음 `http://localhost:4173` 접속.

## 조작 방법

- 이동: 방향키 좌/우 또는 `A`, `D`
- 발사: `스페이스`
- 적을 맞추면 점수가 오릅니다.
- 적이 플레이어에게 닿거나 바닥까지 내려오면 게임 오버입니다.
- `다시 시작` 버튼으로 즉시 재시작할 수 있습니다.
